## First trial and focused correction

[Run 41224123601](https://github.com/astraea-emu/nx2-lab/actions/runs/41224123601) built all 1443 CLI steps and observed native classification, the guest's own debug message, and its ExitProcess request. It nevertheless failed: valid status **124**, invalid status **137** with an empty log. A `k_thread.cpp:140` priority-mask assertion preceded guest execution.

The assertion came from NX2's fixture: main-thread priority byte `0x0E` was zero, while the supplied capability admits priorities 16–63. Set this byte to **44**, the frozen emulator's existing default; the NSO and guest instructions remain byte-for-byte unchanged. See the [fixture correction](eden_native_exefs_fixture_2026-10-30.md). Reuse the source-pinned lifecycle overlay already observed to produce adapted-NRO status 0 and malformed-NRO status 1 in [run 41223767907](https://github.com/astraea-emu/nx2-lab/actions/runs/41223767907).
